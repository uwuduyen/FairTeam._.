# FairTeam — Node 24 / GitHub version

This version is prepared for Node.js 24 LTS and uses the current better-sqlite3 13.x line.

## Windows setup
1. Confirm `node -v` shows v24.x.x.
2. Open Command Prompt in this folder.
3. If a previous install failed, delete `node_modules` and `package-lock.json` if they exist.
4. Run `npm install`.
5. Run `npm start`.
6. Open http://localhost:3000

You should not need Python or Visual Studio Build Tools for the normal prebuilt installation.

## GitHub
Do not upload node_modules/, database/*.db, or .env.
